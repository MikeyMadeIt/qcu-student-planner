# Security Policy

## Supported Versions

This project ships as a single deployed instance (no parallel major-version
branches in production), so the current `main`/deployed version is always the
one that receives security fixes.

| Version        | Supported |
| -------------- | --------- |
| Current deploy | ✅        |
| Older commits  | ❌        |

If you believe you've found a security vulnerability in the QCU Student
Planner, please report it privately rather than opening a public issue:

- **Preferred:** open a [GitHub Security Advisory](../../security/advisories/new)
  on this repository (private by default, visible only to maintainers until
  resolved).
- **Alternative:** email the maintainer directly (see the repository owner's
  GitHub profile) with the subject line `SECURITY: <short description>`.

Please include: what you found, steps to reproduce, and the potential impact.
Avoid accessing or modifying other users' data beyond what's needed to
demonstrate the issue.

**What to expect:**
- Acknowledgement within a few days.
- An assessment of severity and a rough timeline once the report is reviewed.
- Credit in the fix's release notes, if you'd like it, once the issue is
  resolved and disclosed.

Please do not publicly disclose a vulnerability until it has been fixed.
