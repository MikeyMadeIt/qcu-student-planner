# Bootstrap Icons to Lucide migration inventory

## Pre-edit audit

- Branch: `dev/mikey` (the active development branch).
- Bootstrap icon token matches: 999 occurrences in tracked HTML, CSS, and JavaScript, including one dynamic chevron prefix. The scan found 200 distinct tokens: 199 complete icon names and that one prefix. All 999 occurrences were mapped.
- Bootstrap Icons source: Bootstrap Icons 1.11.3 stylesheet and font loaded from jsDelivr by the HTML pages, with matching CDN cache routing in `service-worker.js`.
- No Bootstrap Icons npm dependency or project-local icon font was found. The project is static HTML/CSS and vanilla JavaScript with shared UI generated by JavaScript.
- Contexts found: landing page, authentication, student and admin navigation, topbar and mobile shell, dashboard and app pages, forms, modals, tables, notes editor and repository, AI study tools, notifications, empty states, toast and confirmation dialogs.
- CSS icon-specific rules are concentrated in `assets/css/components/icons.css`, with additional selectors in schedule, date picker, attendance, auth, AI tools, and related page styles.
- JavaScript-generated icons include shared navigation, date/time controls, dialogs, toasts, notes, schedules, calendars, task and subject forms, AI tools, and admin pages.

## Post-migration verification

- All 999 inventoried icon-token occurrences were replaced. The 33 Bootstrap Icons CDN stylesheet tags are gone.
- The runtime now renders from a local sprite containing the 171 distinct Lucide symbols used by the application. The 1.79.0 subset is 38,372 bytes before transfer compression and is precached by the service worker.
- No Bootstrap Icons dependency existed in `package.json`, and no Bootstrap Icons local font assets existed to remove. The Bootstrap CSS and JavaScript CDN references remain intact.
- The service worker no longer has Bootstrap Icons CDN routing. The initial migration advanced its cache key to `qcu-planner-v9`; the Lucide sprite dependency repair later advanced it to `qcu-planner-v10` so installed apps replace the cached sprite.
- Remaining Bootstrap Icons text appears only in this historical inventory and in the regression test that asserts HTML pages no longer load the old CDN. No runtime source references remain.
